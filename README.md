# Shiftrio Foundation

Build the first UI foundation for Shiftrio, a premium mobile-first workforce and shift management app for industrial/construction businesses. Create a polished responsive app shell with Shiftrio branding, role-aware Login screen (Admin/Staff), Staff Home with Start Shift CTA, and Admin Dashboard with Active Shifts, Workers, Sites, Attendance, and Live Activity. Use realistic sample data, reusable Tailwind/shadcn components, and keep the architecture ready for later GPS, photos, shift timer, machines/operators, reports, and Tamil/English support. UI first; no payments or external integrations.
